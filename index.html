① 首页 · 库存总览
一眼看清家里有什么、什么快过期了
  • 顶部三卡：在库 / 临期 / 过期 数量一览，点卡片可快速筛选对应状态。
  • 搜索框（全字段）：输入关键词即匹配 名称/条码/位置/分类/品牌/规格/净含量/厂商/价格；支持 token 通配符——#分类 筛某分类、@位置 筛某储存位置、#待设置/@待设置 筛未设置分类/位置的商品、?空价格/?空净含量 筛对应字段为空的商品、&正常/&临期/&过期 筛对应状态商品；空格分隔可叠加（如 #乳品蛋类 @冰箱冷藏 &正常）。筛选弹层按钮会自动把通配符填进搜索框。
  • 筛选弹层：点「筛选」按 状态/分类/位置 组合过滤、排序、设日期范围；弹层按钮会自动把通配符填进搜索框。
  • 扫码搜索：点搜索框右侧相机图标可扫码定位某条码商品。
  • 商品卡：名称 + 位置/分类标签（未选显示灰色「待设置」），右上圆形为数量。
  • 状态色：左边条与到期文字随临期变化——新鲜绿 / 临期橙 / 过期红。
  • 三按钮：+1 入库 / −1 吃完 / 编辑。
  • 过期提醒：首页右上角铃铛随时看临期/过期清单。
提示：库存数量只能在首页用 +1/−1 调整，编辑弹窗里不可改数量。
首页：token 通配符搜索（#/@/?/&）+ 筛选弹层 + 状态色随临期变化
  • 顶部铃铛出现红点 = 有商品已过期，点开优先处理，避免吃了坏东西。
  • 列表默认按临期排序：越接近过期的越靠前，先吃快坏的，减少浪费。
② 扫码 · 录入新商品
扫条码自动识别，三步完成入库 · 也支持小票批量录入
  • 扫条形码：条形码位于「基础信息」卡第一项——点输入框右侧相机图标扫码，或手动输入条码后点「查询」。
  • 三级回退：GS1 官方库 → 通用商品库 → 进口商品库，自动填充名称/品牌/规格/净含量/厂家/图片。
  • 缓存更新：查过的码显示「更新」，再点一次强制走 API 刷新为最新数据。
  • 分类 / 位置多选：一个商品可同时勾选多个分类与多个位置——例如录入「芝士」，分类勾选 乳品蛋类 + 调味品，位置勾选 冰箱冷藏。都不选 =「待设置」，以后可在首页/编辑里补。
  • 日期三联动：生产日期 / 保质期（日·月·年 可切换）/ 到期日期，任填两项第三项自动算出。
  • 净含量 / 总价 / 初始数量：净含量写单件含量（如 250ml，右侧小字「·单件商品」提示）与总价并排一行；初始数量为本批入库件数。三者分清，统计才准。
  • 更多信息（折叠）：品牌、生产厂家、商品图片、入库日期（自动锁定，批量录入另有备注），可扫码自动带出。
  • 填好点 提交入库 即完成（商品名称必填）。
  • 小票批量录入：扫码页顶部另有「小票批量录入」入口——一次录入多件商品，支持「拍摄小票」直接拍照或「上传图片」读取图片，自动识别商品名 / 条码 / 金额，点击识别结果即可添加为商品，再手动补充日期等信息；电脑浏览器点「拍摄小票」会打开内置摄像头实时预览拍照，手机则直接调用原生相机。最后点「+ 添加商品」逐条补录、或改完直接「保存全部」一次性批量入库（入库记录标记「批量入库」）。
提示：开启「条码查询增强」（设置里）才能自动识别商品信息；不开启也能手动填写。
扫码页：条码查询 + 日期三联动 + 分类/位置多选（芝士：乳品蛋类+调味品 / 冰箱冷藏）
  • 三级回退都查不到时，仍可手动填名称/品牌继续入库，不影响后续统计。
  • 「更多信息」折叠区可贴商品照片，下次同码扫码会自动带出，省得重填。
  • 小票识别采用「双通道」策略：先常规文字识别（chi_sim+eng），再用 EAN/UPC 校验位从识别文本里捞条码；未命中时换灰度图 + 数字白名单二次识别——彩色条码 / 反光 / 褶皱的小票也能识别出来。
  • 批量录入的「保存全部」会一次性写入多件商品，且每件都会生成一条「批量入库」记录，可进入「记录」页查看。
③ 记录 · 操作历史
所有入库 / 吃完 / 浪费 / 调整一目了然，还能撤销
  • 快捷筛选：顶部「在库 / 入库 / 消耗 / 浪费」一键切换对应记录。
  • 搜索定位：搜索框全字段模糊匹配（商品名 / 条码 / 操作详情），或点相机图标扫码定位某条码的所有记录。
  • 高级筛选：点「筛选」按 记录类型 + 日期范围 组合过滤（激活后按钮变橙并带圆点）。
  • 分组展示：记录按 今天 / 昨天 / 具体日期 分组，每组显示条数。
  • 记录内容：类型徽章（入库橙/吃完绿/浪费红/调整蓝）+ 商品名 + 数量 + 时间 + 备注。
  • 撤销：每条右侧「撤销」可移除该记录并回滚库存（弹窗预览数量 from→to），撤销后到首页补填缺失信息即可。
提示：撤销会同时影响统计与库存，误撤可在首页用 +1/−1 补回。
记录页：按日期分组，类型色条 + 一键撤销
  • 撤销 ≠ 删除商品：只移除这条记录并把数量回滚，商品仍留在库里。
  • 高级筛选单独勾「浪费」，可快速定位家里总在丢什么，针对性少买。
④ 统计 · 趋势与金额
看清浪费在哪、钱花在哪，越用越省
  • 时间范围：顶部预设「今日 / 近一周 / 近一月 / 本年度」，或自定义起止日期；所有指标随范围联动。
  • 浪费 · 临期：浪费率、临期金额、浪费金额、浪费净含量，一眼看清损耗重点。
  • 近 6 月趋势：采购 / 消耗 / 浪费 三色柱状对比（红柱为浪费），柱顶为单月件数，可发现囤货与短缺规律。
  • 当期金额：采购金额与消耗金额大字并排展示，附日均金额与累计件数，底部为净支出（采购 − 消耗）。
  • 库存状态：甜甜圈展示正常 / 临期 / 过期占比，中心为总件数与临期占比；点击状态标签可跳到首页按该状态筛选。
  • 分类 / 位置分布：两个甜甜圈展示分类与储存位置占比；点击图例可跳到首页按标签或位置筛选。
  • 库存经济：库存货值、可吃天数、已过期件数，评估当前库存的资金占用。其中可吃天数 = 当前库存件数 ÷ 近 30 天日均消耗件数，随「吃完/浪费」记录积累越来越准；刚使用时因日均消耗基数小，数值参考意义有限。
  • 数据质量：未填价格 / 净含量、标签或位置待设置的数量，点击可跳到首页补全对应字段。
提示：浪费金额/净含量按记录时快照的单价统计，单价从使用后自动积累，越用越准。
统计页：浪费临期 + 三色趋势 + 当期金额 + 甜甜圈分布
  • 切换时间范围后所有数字联动，对比「近一周」与「本年度」能看出近期是否囤多了。
  • 库存状态、分类/位置图例与数据质量均可点击跳转首页筛选，发现问题可直接补全。
⑤ 设置 · 个性化与同步
调好这些，FoodIn 才真正顺手
  • 使用指南：设置页顶部入口，随时回看本指南。
  • 即将到期判定：填「到期前 N 天」算临期（默认 7 天），决定首页/铃铛的临期提醒。
  • 存储位置列表：添加位置；编辑模式下拖动排序、点名称重命名、点 × 删除（如 冰箱冷藏/冷冻/橱柜）。
  • 商品分类列表：同上管理分类（粮油米面/调味品/生鲜果蔬…）。
  • 云端数据同步：注册 jsonbin 的 API Key + Bin ID 即可开启；多设备按事件全序增量收敛（如妈妈 −1 + 爸爸 −2 = 云端 −3，互不覆盖），支持立即同步、自动保存间隔，断网恢复自动补同步。
  • 安装到主屏（PWA）：手机浏览器「添加到主屏」即可像 App 一样打开，图标为购物篮；v2.18.2 起已优化启动图标显示，避免被系统裁切。
  • 条码查询增强：开关 + 可选 API Key，开启后扫码自动识别商品信息（三级回退）。
  • 导出 / 导入 / 清空：导出 JSON 备份；导入合并不覆盖新数据；清空全部数据⚠ 慎用（开云同步会同步清空所有设备）。
  • 版本：底部点版本号查看更新日志。
提示：换手机或重装前，记得先「导出备份」存一份 JSON，随时可「导入」恢复。
设置页：临期判定 / 位置分类 / 云同步 / 备份
  • 拖动排序：位置/分类编辑模式下长按手柄拖动，顺序会同步到首页筛选与下拉。
  • 导出 JSON 建议每月一次，换手机或重装前务必先做，导入可合并不覆盖。
