# versions/ — 版本档案

> **历史档案，永不删除。** 回退方式：`cp versions/vX.Y.Z/* .`
> （若该版本间新增过 Tailwind utility class，回退后还需按该版本重编译 `styles.css`）

## 一、每个目录应当装什么

`vX.Y.Z/` 应存放**该版本发布时**的三件套：`index.html` + `service-worker.js` + `styles.css`。

## 二、归档纪律（历史事故的教训）

1. **必须在 bump 完成后备份** —— 即先改 `CURRENT_VERSION`（与 SW `CACHE_NAME`），**再** `cp` 三件套。
2. 历史上有若干次是「**bump 前**备份」，于是目录里留下的是 **上一个版本的代码 + 尚未升版的改动**，
   目录名比内部版本号大一位 → 按文档回退会**退到错误的版本**，极难排查。
3. `versions/` 由 `push-safe.sh` 全量提交（`git add versions/`），文件名不要以 `_` 开头（会被 `.gitignore` 屏蔽）。
