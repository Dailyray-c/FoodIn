# 食品库存管理系统 · 界面规范

> 本规范是界面开发/改版的口径文档，所有改动必须遵循。版本：v2.15.7（2026-08-28）

## 1. 字号规范（三档制，禁止再出现任意像素字号）

| 档位 | 类名 | 用途 | 备注 |
|---|---|---|---|
| 20px | `text-xl` | 顶部大数字（在库/采购/消耗/浪费/统计概览） | 唯一的大数字档 |
| 16px | `text-base` | 页面标题、弹窗标题 | |
| 14px | `text-sm` | 商品名、按钮文字、设置项标题 | 正文主档 |
| 12px | `text-xs` | 字段标签、chip、统计数字、分组标题、底部导航 | 文字下限 |
| 11px | `text-[11px]` | 次要辅助文字（统计指标标签、状态标签、更多信息字段、设置说明） | 允许的最小字号 |

**禁止**：`text-[10px]`、`text-[9px]` 及更小字号；禁止其他任意像素字号（`text-[13px]` 等）。

## 2. 颜色规范

### 中性文字
| 色值 | 用途 |
|---|---|
| `text-gray-400` | 次要说明、元信息 |
| `text-gray-500` | 次级标签、辅助提示 |
| `text-gray-600/700` | 正文 |
| `text-gray-800` | 标题/强调 |
| `text-gray-300` | 仅用于"空态/禁用"弱提示 |

### 语义色（不可互换）
| 色值 | 语义 |
|---|---|
| 红 red-500/600 | 浪费、过期、危险、负数 |
| 橙 orange-500/600 | 主操作按钮、临期主色 |
| 琥珀 amber-600/700 | 采购、临期 |
| 绿 green-600/700 | 吃完、正常 |
| 蓝 blue-600/700 | 在库、净增 |
| 紫 purple-500/600 | 分类 |
| 青 teal-500/600 | 储存位置 |
| 灰 gray-500 | 「待设置」（选中态灰底白字） |

## 3. 间距规范

| 场景 | 要求 |
|---|---|
| 表单标签 → 输入框 | `mb-1.5`（6px）起步，不得用 `mb-1` |
| 统计卡 标签 → 数字 | `mt-1.5`（6px）起步，不得用 `mt-1` |
| chip/标签内边距 | `py-1` 起步（禁止 `py-0.5`） |
| 表单纵向间距 | `space-y-3`（12px） |
| 卡片内边距 | `p-4`（16px） |

## 4. 文案术语表（全站统一叫法）

| 术语 | 说明 |
|---|---|
| 在库 / 临期 / 过期 | 商品状态（主页顶部三按钮） |
| 入库 / 吃完 / 浪费 / 调整 | 记录类型（四分类） |
| 待设置 | 分类/位置为空时的统一叫法（代替"未分类/未归位"） |
| 基础信息 / 日期信息 / 更多信息 | 表单分组标题（扫码页与编辑弹窗一致） |
| 采购 / 消耗 / 浪费 / 净增 | 统计页概览指标 |
| 消耗 = 吃完 + 浪费 | 统计口径 |
| ·多件为总价 | 价格字段标注（统一文案） |
| 数据统计 / 记录 / 设置 | 页面导航标签 |

## 5. 布局规范

- 扫码页：条形码（独立白卡）→ 商品信息（白底大卡：基础信息 + 日期信息分组）→ 更多信息（独立折叠块）→ 提交按钮；
- 编辑弹窗「更多信息」与扫码页「更多信息」**完全同构**（标题/内边距/字段排列一致）；
- 所有「更多信息」块：默认折叠、标题同分组标题样式、无折叠摘要文字。

## 6. 版本发布流程

1. 改代码 → 2. 语法校验（node new Function 所有 script 块 + `node --check service-worker.js`）→ 3. 版本号 +1（`CURRENT_VERSION`）→ 4. changelog 置顶 → 5. SW `CACHE_NAME` 版本 +1 → 6. 直接部署（**不要先下线**，链接不变）→ 7. 更新 `memory/YYYY-MM-DD.md`。
