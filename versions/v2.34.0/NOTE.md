# ⚠️ 本目录不是 v2.34.0 的发布快照

- **内部实际版本**：`CURRENT_VERSION = '2.33.0'`，SW `food-inventory-v114`
- **目录名（v2.34.0）与内部版本不一致** → **不要**用 `cp versions/v2.34.0/* .` 回退，那会退到 **2.33.0**。

## 原因

v2.34.0 **从未单独提交**。git 历史里 2.34.0–2.34.3 合并为**一次发布**：

```
2bbd5d3  release(v2.34.0–2.34.3)   → 内部 CURRENT_VERSION = 2.34.3，SW = v116
```

本目录是「**bump 前**备份」的产物：捕获的是 2.33.0 的代码 + 尚未升版的 2.34.x 改动。

## 应该用什么回退

| 目标 | 用哪个目录 |
|---|---|
| 回到 2.34.x（含百度云 OCR 三引擎 / 高级设置独立页等） | `versions/v2.34.3/`（2.34.3 / v116，与提交 `2bbd5d3` 基本一致） |
| 回到 2.33.0 | `versions/v2.33.0/`（2.33.0 / v114，与标签 `v2.33.0` 逐字节一致） |

详见 `versions/README.md`。
