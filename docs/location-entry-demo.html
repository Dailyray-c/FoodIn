数据模型（预留接口）

places: [
  { name: '冰箱',   zones: ['门架','冷藏','冷藏下层','冷冻'], layout: 'fridge' },  // 剪影
  { name: '餐边柜', zones: ['左柜','右柜'],                     layout: ''       },  // 分区清单（预留 layout）
  { name: '厨房',   zones: [],                                  layout: ''       },  // 无分区：直接商品清单
]

layout 字段 = 展示形态接口：fridge=冰箱剪影（已定稿）｜空=分区清单｜后续其它地点要画剪影只加一种 layout 值即可，商品数据与录入控件零改动。
